# Privacy Policy

Last updated: 8 September 2026

## Overview

VibeZ is an independent, open-source Linux desktop client that opens the Mistral Vibe web application in an Electron window. VibeZ does not operate its own backend service and does not include analytics, advertising trackers or telemetry.

## Mistral Vibe data

When you use VibeZ, the application loads `https://vibe.mistral.ai/`. Messages, account details, uploaded images and other information you enter in the Vibe web application are sent to and handled by Mistral's service. Their data handling is governed by Mistral's own terms and privacy policy.

VibeZ restricts in-app navigation and permission handling to trusted Mistral pages. External links are opened in your normal web browser when that option is enabled.

## Local data on your device

Like a web browser, the embedded Vibe web application may store cookies, cache files and local website data on your device. This can include information needed to keep you signed in to Mistral Vibe.

VibeZ also stores its own desktop preferences locally, including settings such as screenshot shortcut, tray behavior, start-at-login preference, display backend, hardware acceleration, zoom, language and update preferences. The settings file is stored locally with user-only file permissions where supported.

VibeZ does not transmit or sell these local settings or browser data.

## Screenshots and clipboard

The Screenshot feature captures only the area you select. The resulting image is placed on your local clipboard. In supported Vibe Chat and Work views, VibeZ can paste that clipboard image into the Mistral Vibe composer. At that point, sending or processing the image is handled through Mistral Vibe.

In Vibe Code, VibeZ keeps the screenshot on the local clipboard and provides guidance for saving it into your own project. VibeZ does not operate a separate screenshot upload server.

The global screenshot shortcut is registered locally by the desktop application and can be disabled or changed in Settings.

## Start at login and system tray

If you enable **Start VibeZ at login**, VibeZ asks the operating system to start the application when you sign in. Tray, minimize-to-tray and close-to-tray preferences are handled locally on your device.

## Update checks

Installed releases of VibeZ can check GitHub Releases for updates. This may send a request to GitHub and reveal standard technical information such as your IP address and the app version to GitHub, in accordance with GitHub's policies.

Automatic update checking can be disabled in VibeZ Settings.

## Network connections

VibeZ needs network access to load Mistral Vibe and, when update checking is enabled, to contact GitHub Releases. User-invoked external searches or links may open third-party websites in your normal browser.

VibeZ does not send application data to a Le Computeur server because no such backend is operated by this project.

## Third-party services

- **Mistral Vibe** provides the web application used within VibeZ.
- **GitHub** hosts the source code, release files, checksums and update metadata.
- External websites are opened only through user actions such as following links or using a search action.

## Changes to this policy

If VibeZ's data handling changes materially, this policy will be updated in the repository.
