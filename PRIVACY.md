# Privacy Policy

Last updated: 23 August 2026

## Overview

VibeZ is an independent, open-source Linux desktop client that opens the Mistral Vibe web application in an Electron window. VibeZ does not operate its own backend service and does not include its own analytics or advertising tracker.

## Mistral Vibe data

When you use VibeZ, the application loads `https://vibe.mistral.ai/`. Messages, account details, and other information you enter in the Vibe web application are sent to and handled by Mistral's service. Their data handling is governed by Mistral's own terms and privacy policy.

## Local data on your device

Like a web browser, the embedded Vibe web application may store cookies, cache files, and local website data on your device. This can include information needed to keep you signed in to Mistral Vibe. VibeZ does not read, transmit, or sell this local website data itself.

## Update checks

Installed releases of VibeZ check GitHub Releases for updates when the application starts. This may send a request to GitHub and reveal standard technical information such as your IP address and the app version to GitHub, in accordance with GitHub's policies.

## Network connections

VibeZ needs network access to load Mistral Vibe and, in installed releases, to check for updates. VibeZ does not send application data to a Le Computeur server because no such backend is operated by this project.

## Third-party services

- **Mistral Vibe** provides the web application used within VibeZ.
- **GitHub** hosts the source code, releases, and update files.

## Changes to this policy

If VibeZ's data handling changes materially, this policy will be updated in the repository.
