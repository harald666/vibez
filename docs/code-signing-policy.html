Security · Release integrity

Code signing policy

VibeZ is preparing signed production releases for VibeZ 2.0. The current VibeZ 1.x Windows and macOS releases remain unsigned until the new signing pipeline is enabled and verified.

Windows

VibeZ plans to use SignPath for Windows release signing. When the VibeZ 2.0 Windows signing pipeline is activated, Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Only binaries produced from the official VibeZ source repository by the project's GitHub Actions release workflow are eligible for signing.

macOS

VibeZ 2.0 macOS production builds are planned to use an Apple Developer ID Application certificate, Hardened Runtime and Apple notarization before publication.

Project roles

  • Committer: @lecomputeur
  • Reviewer: @lecomputeur reviews external contributions before merge.
  • Signing approver: @lecomputeur

Privacy

See the VibeZ Privacy Policy. VibeZ connects to the Mistral Vibe service at the user's request and to GitHub for release/update checks. VibeZ does not independently sell user data or operate an advertising network.

Release integrity

Official releases are built with GitHub Actions from the public repository. Release downloads include SHA-256 checksums. Signed VibeZ 2.0 production artifacts will be published only after automated build verification and platform signing checks succeed.
