VibeZ

A free Linux desktop client for Mistral Vibe.

Download VibeZ View on GitHub

Available for your Linux distribution

DEB

Debian, Ubuntu & Mint

Install the native Debian package with your software installer or apt.

RPM

Fedora

Install the native RPM package with your software installer or dnf.

APPIMAGE

Any compatible Linux system

Use the portable AppImage without a traditional installation.

Simple by design

VibeZ opens the official Mistral Vibe web app in a focused desktop window and checks GitHub Releases for updates.

VibeZ is an independent project and is not affiliated with or supported by Mistral AI. A Mistral account may be required to use Vibe.
