Which Windows installer should I download?

VibeZ publishes separate Windows installers so you do not need one oversized cross-platform package.

  • Most Windows PCs: choose the file ending in Windows-x64.exe.
  • Windows on ARM: choose the file ending in Windows-arm64.exe.

What does VibeZ add on Windows?

VibeZ opens the official Mistral Vibe service in a dedicated Electron desktop window and adds a global screenshot shortcut, multi-monitor screenshot selection, system-tray access, start-at-login support, configurable desktop settings and a VibeZ interface available in 34 languages.

Windows SmartScreen and unsigned builds

VibeZ is distributed without a paid Windows code-signing certificate so the project can remain free. Windows SmartScreen may therefore show Windows protected your PC or Unknown publisher the first time you run the installer. Only continue when you downloaded VibeZ from the official GitHub repository. Release downloads include SHA-256 checksums for integrity verification.

Updates on Windows

Packaged Windows versions can check GitHub Releases for VibeZ updates. When supported, VibeZ downloads the update and asks before restarting to install it.

VibeZ is an independent open-source project and is not affiliated with or supported by Mistral AI.
